# Which new incidence or frame families improve the physically realized profile?

Can a change of incidence geometry, coefficient domain or frame family improve the complete profile beyond the current two-stage construction?

The upstream project already studies common subsets, larger frames, paid clones and Gaussian matrix constructions. Choose one concrete family and explain which existing restriction it changes. An abstract low-rank factorization has to be compiled into legal operations with paid coefficient arithmetic and workspace restoration.

**First experiment:** construct the smallest nontrivial example over a specified coefficient domain. Verify the exact terminal map on data and dirty auxiliary inputs, derive the allowed edge ranks or child widths, and include every conversion to the tape representation. Compare it with the closest upstream family at the same dimension.

**Acceptance:** an exact finite witness improving the complete moment at a stated target, or a structural obstruction explaining why the algebraic gain disappears after compilation. State how constants depend on dimension; a network growing with input length requires a new uniform analysis.

**Dependencies:** Q1–Q2; Q4 should guide which restrictions are worth relaxing. A finite catalogue optimum must retain its catalogue qualification.
