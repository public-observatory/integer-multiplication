# Can a small independent verifier check semantics, physical profiles and contraction?

What certificate format permits an independent verifier to check one complete finite network from serialized gates through its recursive child profile and exact moment inequality?

The upstream arithmetic audit already reconstructs child multiplicities from stored profiles. Extend the trusted path to physical semantics rather than merely wrapping that checker. For a linear circuit, equality on every basis vector proves equality on every input; include the auxiliary coordinates and both required orientations. Exact ranks need rational elimination or a proved minor bound with enough modular information, not agreement at a few primes.

**First experiment:** use a small legal instance with dirty workspace. Change one endpoint, omit a cleanup and corrupt a child count in three separate negative controls. The checker must reject each for the corresponding reason. Define exactly what it trusts about a compressed certificate.

**Acceptance:** a published certificate schema, a short independent checker, a successful complete replay of the small instance and the negative controls. Scaling to the selected large network is a subsequent milestone; a small instance alone does not validate it.

**Dependencies:** Q1 supplies the intended contracts.
